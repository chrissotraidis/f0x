# F0X artwork

`AppIcon.xcassets` contains the original F0X iOS/iPadOS application icon. The
opaque 1024 x 1024 master is the source of truth; Xcode's asset-catalog compiler
produces the device-specific icon renditions and applies the platform mask.

The artwork was generated for this repository with OpenAI's built-in image
generation tool on 2026-08-13, then selected and validated at home-screen size.
It uses an original F0X monogram and intentionally contains no Nintendo game
art, characters, vehicles, screenshots, or official F-Zero logo artwork.

Final prompt summary: create a premium, vector-like Apple app icon centered on
an exact `F0X` speed monogram, with a graphite background, red-orange mark, and
restrained electric-blue accent; keep it opaque, full bleed, readable at 20 px,
free of baked rounded corners, and free of copyrighted game imagery.
