Follow-up (same day): layouts aligned exactly with the HarkinianPad reference
-----------------------------------------------------------------------------
- Default geometries were reworked to the accepted HarkinianPad physical
  layouts (customizable-touch-controls.patch promoted centers + grip-first
  design base frames), using full-window normalized centers like the
  reference. The live overlay's reported frames match the reference fractions
  exactly on the iPad Pro 11-inch (M5) Simulator:
    stick (0.164, 0.745), ACCEL/A (0.893, 0.693), BOOST/B (0.826, 0.635),
    BRAKE/C-down (0.902, 0.905), VIEW/C-right (0.948, 0.853),
    LOOK/C-up (0.903, 0.805), C-left (0.857, 0.854), SLIDE L/Z (0.193, 0.613),
    SLIDE R/R (0.921, 0.518), L (0.059, 0.518), START (0.845, 0.518),
    D-pad group (0.079, 0.606) — the tablet fractions; the phone table uses
    the reference's accepted compact fractions with the same control mapping.
- Reference colors applied: A blue, B green, C buttons amber, L/Z/R the
  neutral dark pill/face, Start red.
- The permanent ••• button follows the reference slots: tablet upper-right,
  phone top-center during gameplay and bottom-center while the menu is open.
- Z hold-to-latch on SLIDE L (the reference's shared Z latch): ~0.5 s hold

  cancel path (menu open, editor, background, interruption, release) clears
